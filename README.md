# VisionDesk AI

### Multimodal Intelligent Reception & Visitor Assistant System

VisionDesk AI is an AI-powered intelligent reception system designed to transform traditional front-desk operations through multimodal interaction. It enables visitors to communicate naturally using voice, video, and text while providing intelligent assistance and reception services.

## Key Features

- **Voice Interaction:** Real-time voice-based communication with visitors.
- **Visual Interaction:** Camera-enabled visitor detection and visual assistance.
- **Text Interaction:** Text-based communication and visitor support.
- **Smart Reception Assistance:** Helps visitors navigate departments and access relevant information.
- **Visitor Management:** Supports visitor-related reception workflows.
- **Admin Dashboard:** Centralized interface for administrative operations.

## Technology Stack

| Category | Technologies |
|---|---|
| Frontend | React, TypeScript, Vite |
| Backend | Node.js, Express |
| AI Integration | Google Gemini Live API |
| Authentication | Firebase Authentication |
| Database | PostgreSQL, Drizzle ORM |
| Real-time Communication | WebSocket |

## Getting Started

### Prerequisites

- Node.js
- npm
- Docker Desktop (for local PostgreSQL database)

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/kuldeep-suman/VisionDesk-AI.git
   ```

2. Navigate to the project directory:

   ```bash
   cd VisionDesk-AI
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Configure the required environment variables using `.env.example`.

5. Start the development server:

   ```bash
   npm run dev
   ```

6. Open your browser and visit:

   `http://localhost:3000`
